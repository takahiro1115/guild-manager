# 冒険者ギルドマネージャー（仮称）― 開発ドキュメント一式

Godot 4.7.2（C# / .NET 8）で開発する経営シミュレーションの企画・設計文書。
**Git で管理し、開発しながら育てる**前提で作成。数値は全て暫定（叩き台）。

## 文書構成

| ファイル | 役割 | 詳細度の方針 |
|---|---|---|
| `01_コンセプト.md` | 誰の・どこが面白いゲームか（最上位・不動） | 短く言い切る |
| `02_コアループとMVP.md` | 中心の輪と、最初に作る最小版 | 図＋箇条書き |
| `03_システム仕様_v2.0.md` | メカニクスの詳細（v1.0の矛盾修正・欠落補完に加え、実装済みコードとの内容同期済み） | 式・ルールまで／数値は 04 参照 |
| `04_バランス表/` | 調整対象の数値をCSVで集約（実行時に読み込む正本、→ 03 §10.1） | 網羅・暫定・頻繁に変更 |
| `05_技術メモ.md` | 構成・セーブ形式・乱数・UIスケール（TDD） | 軽量・コードと共に更新 |
| `06_タスクリスト.md` | 次に作る順序（Issue 化してよい） | 次の数手が分かれば十分 |

## 読む順番

初めて見る人は `01 → 02 → 03` の順。実装に入るときは `05` と `06` を手元に、
数値をいじるときは `04` を開く。

## 開発の進め方（要約）

1. **Phase 0**：環境構築・Godot学習・2プロジェクト構成（Core分離）・Git開始 — 完了
2. **Phase 1–2**：MVP（編成→週送り→結果→資金 が一周する骨組み） — 完了
3. **Phase 3**：機能追加 — 完了。加齢・人事・格付け（後に撤廃）・7職業拡張・8年稼働制に加え、
   **大迷宮5フィールド**と**アルベールの研究室（二軸経済）**を実装し、遊びの中心を
   旧・通常クエストから大迷宮へ完全に移した。
4. **Phase 4**：バランス外部化・セーブ・UI刷新・**旧仕様の一掃** — 完了。
   全ての調整値を `04_バランス表/` のCSVへ外部化し、主要パネル（大迷宮・部隊編成・
   冒険者管理）のUIを刷新。あわせて、大迷宮への一本化で役目を終えた旧仕様
   （通常クエスト・治安／脅威度・昇格試験・旧環境ギミック評価器・生涯ピーク値・
   到達不能な年齢帯）をコード・CSV・仕様書から撤去し、実働する定義だけが残る状態にした
   （→ `03` §0.8〜§0.13）。
5. **Phase 5**：世代交代と新機能（post-MVP） — 進行中。
   **ハクスラ的な報酬ループ（遺物→鑑定→保管庫→装備／売却）を一周させ、離脱時の装備回収まで
   繋いだ**（→ `03` §0.14〜§0.16・§4.7・§4.8）。あわせて部隊指標の差別化（走破力／隠密）と
   大迷宮画面の1920×1080収容を完了（→ `03` §0.17〜§0.18）。さらに道中損耗の階層別積み上げと
   判定数値の完全開示、名声・格付け・助成金の撤去と「マスターの機嫌」への刷新、内職強化研究と
   除籍時の激怒、相性上昇の大迷宮再配線と「田舎育ち」の再設計を完了（→ `03` §0.19〜§0.22）。
   残る優先順は【候補A】銘入り装備（ネームド／遺産ボーナス）→【候補B】ハクスラ武具のランダム
   アフィックス生成 →【候補C】最深部（深淵20F／100F）制覇によるクリア判定・エンディング。

**テスト状況：** `GuildManager.Core.Tests` の xUnit テスト **845件全件合格**（ビルド警告・エラー0件）。

詳細は `02` と `06` を参照。

## 更新のルール

- 決定が変わったら `03` / `05` を直し、**理由をコミットメッセージに残す**。
- 遊んで出た数値調整は **`04` 側だけ**で行う（`03` には数値を書かない）。
- `04` は実装で CSV/JSON に書き出し、C# の Core が読み込む（`05` §3）。

## v2.0 到達点での主な仕様（現行バージョン要約）

詳細は `03_システム仕様_v2.0.md` の §0〜§0.22（改訂履歴）と各章を参照。

- **大迷宮攻略システムへの一本化**：全5フィールド（各100階層・10階刻みで階層ボスを配置）。
  任務は3大任務＝**潜行**（毎回1階層から潜る複数週の道中進軍、扉前で「挑む／撤退」を指令）・
  **調査**（迷宮調査でボスの解析率を上げる）・**採取**（フィールド固有素材とゴールドの獲得）。
- **二軸経済とアルベールの研究室**：ゴールド（給与・雇用・施設投資）と素材（研究投資）を分離し、
  ゴールド＋素材を投じて恒久的なインフラバフ（HP回復・解析率・採取数・走破力・生存）を得る。
- **7職業への拡張**：Knight・Thief・Scholar を追加。成長重みは全職業で合計9に統一し、
  前衛/後衛の役割表示（火力には影響しない。配置補正は撤廃済み）と装備制限を7職業分定義。
- **8年稼働・26歳満期引退モデル**：加齢による衰微は完全廃止。加入は18歳固定で、稼働8年
  （26歳の年度末）に満期引退し、退職金（週給×規定週数＋累積功績×係数）を支払う。
  年齢帯は実働する**3区分（新鋭期〜18／成長期19〜22／全盛期23〜）**のみ。
- **女性限定ギルド**：`Gender` は `Female` のみ。男性が混入する余地を型そのもので排除している。
- **マスターの機嫌（名声・ギルド格付けを撤廃）**：ギルドはマスター・アルベールの私設組織で、
  プレイヤーはその副官。機嫌（0〜100、初期50）は大迷宮での成果（ボス撃破+20・新階層開拓・調査・採取）と
  鑑定で上がり、成果ゼロの週は退屈して−5、隊員の強制除籍では激怒して1名につき−20（→ `03` §8.1）。
- **収入はアルベールの市販薬・内職売上（公的助成金を撤廃）**：4週に1回、(基本200G＋内職強化研究の加算)×
  機嫌倍率（上機嫌1.5／平常1.0／不機嫌0.5／危機0.0）を入金する。採取素材を内職強化研究4種へ投じると
  基本額が恒久的に上がる（→ `03` §8.1・§4.6）。
- **敗北条件**：**副官解雇**（マスターの機嫌が0に到達、即時）と**経営破綻**（所持金マイナスが4週連続）の2つ。
  治安崩壊による即時敗北は撤廃し、治安・脅威度システム自体も撤去した（→ `03` §8.3）。
- **道中損耗の階層別積み上げと判定数値の完全開示**：道中進軍のHP損耗は階層ごとに「基礎率×その区間の
  被ダメージ倍率」を積み上げる（解析済み区間の軽減が未解析区間へ漏れない）。開発・バランス調整期間中は、
  出撃前プレビューと週報に判定式・要求値・内訳を完全開示する（→ `03` §4.5.3・§4.2.3）。
- **相性と特性**：大迷宮の任務を達成して生還した隊員同士の相性が上がる（ボス撃破+3、潜行・調査・採取+1）。
  特性「田舎育ち」は採取スコアに本人の寄与の+20%を上乗せする（→ `03` §5.3）。
- **未鑑定遺物と鑑定（ハクスラ的な報酬ループ）**：探索（採取）の確率ドロップと階層ボス撃破の
  確定ドロップで「中身の分からない古代の遺物」が溜まる。アルベールに鑑定費用を払うと、
  希少度4段階（銅・銀・金・虹）ごとの比率で**武具・素材・資金**のいずれかへ化ける（→ `03` §4.7）。
- **ギルド保管庫（Armory）と装備の個体管理**：装備枠が持つのはカタログIdではなく**個体**。
  鑑定で出た武具を着せ替えでき、押し出された旧装備は保管庫へ戻る。引退・除籍・退団の全経路で
  装備は**ギルド備品として保管庫へ自動返還**される（→ `03` §4.2.2）。
- **在庫の売却**：余剰の素材（1個／指定数／全数）と武具を換金できる。武具はカタログ品が定価の50%、
  鑑定品が希少度基準額。金・虹の鑑定品は誤売却防止のため1点ずつ表示する。**解体（素材還元）は
  実装しない**（→ `03` §4.8）。
- **部隊指標の差別化**：走破力＝VIT・MND・隊長LDR（体力と気力）、隠密適性＝AGI・DEX・隊長LDR
  ＋斥候/盗賊ボーナス −人数減衰・重装ペナルティ（潜伏の精度）。同じ式を共有していた2指標を
  別系統に切り分けた（→ `03` §4.5.3）。
- **画面は論理1920×1080**：`project.godot` でビューポートを明示（`canvas_items` スケーリング、
  実ウィンドウは1600×900へ縮小表示）。常設ヘッダーの素材サマリーは撤去し、素材の確認は
  「倉庫・遺物」画面へ集約した（→ `03` §9）。
