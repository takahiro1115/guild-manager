## 3. 気をつけること（このセッションで踏んだもの）

- **Bash のヒアドキュメントで perl を書くと、`\\` や `{}` が崩れることがある**。長い perl は Write ツールで scratchpad に .pl を書いてから実行する。`s{…}{…}` は置き換え先に `{` `}` が入ると壊れるので `s~…~…~` を使う。
- `sed -i` は Git Bash で CRLF を LF にする（コミットでそろうが、作業中の差分が大きく見える）。Edit ツールか perl を使う。
- 画面の確かめ（scratchpad の複製・`config/name` を毎回変える・検証用 autoload）は前の引き継ぎ書どおり。**検証用のスクリプトが確認の小窓に「はい」を押すと月が進む**ので、確かめるときは「やめる」を押すか `AdvanceMonth` を直接呼ぶ。セーブは自動保存で上書きされるので、毎回シミュレーターで書き出し直す（`audit 1 1440 L3 simple notutorial dump=週 dumpdir=<フォルダ>`）。
- 物語帳を書き換えるときは、`ArtifactData` の `list`（`out_dir`）で読み、版（version）を控えてから `batch` で `if_version` を付けて書く。
- 試しの値でバランス表を変えて回すときは、ビルドした `bin/Release/net8.0` を scratchpad に複製してその CSV を書き換える（本物の CSV は触らない）。
