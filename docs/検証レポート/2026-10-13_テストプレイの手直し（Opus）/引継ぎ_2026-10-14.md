## 3. 手順のメモ

- **物語帳の読み書き**：`ArtifactData` の `list`（`out_dir` を付けて JSON で保存）→ perl（`JSON::PP`）で本文を差し替えた JSON を作る →
  `batch` で `if_version` を付けて書く。ユーザーが同時に直していることがあるので、読み直してから書く。node と python は使えない（python3 は空のスタブ）。
- **改行**：作業ツリーは CRLF と LF が混ざっている。Git Bash の `sed -i` は CRLF を LF に変えてしまうので、perl で `\r?\n` を使うか Edit を使う。
  perl の `s///` の置き換え側で `$1` のすぐあとに数字を書くと `$13` と読まれる（`${1}3` と書く）。
- **シミュレーター**：CSV を直したら `dotnet build tools/balance_sim -c Release` で作り直す（CSV はビルド時にコピーされる）。
  `dotnet run --project tools/balance_sim -c Release --no-build -- campaign 10 1440` と `-- audit 30 1440 L3 simple`。10回だと揺れが大きいので、比べるときは campaign 20 も使う。
  長いものは `run_in_background` で回す。
- **画面の確かめ方**：CLAUDE.md の「動作確認」（実セーブを守る。scratchpad にコピーして `config/name` を変える）。
