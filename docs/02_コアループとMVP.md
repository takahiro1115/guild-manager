# 02. コアループと MVP 定義（1ページ）

> ゲームの中心となる「輪」と、最初に完成させる最小版を定義する。
> **最初の目標は「面白い完成品」ではなく「一周まわる骨組み」。** 肉付けは後。

---

## コアループ

プレイヤーが繰り返す中心の輪。ここが気持ちよく回れば、ゲームの背骨は完成している。

```
   ┌─────────────────────────────────────────────┐
   │                                             │
   ▼                                             │
 [編成]  クエストを選び、4名のパーティを組む        │
   │                                             │
   ▼                                             │
 [週送り] 「次週へ」を押す（Space）               │
   │                                             │
   ▼                                             │
 [結果]  索敵→戦闘→負傷/致死 を自動解決、ログ表示   │
   │                                             │
   ▼                                             │
 [人事・資金] 週給引落し・報酬加算・満足度変動・     │
   │          負傷/退団/加齢を処理                 │
   │                                             │
   └─────────────────────────────────────────────┘
              （治安・格付け・施設は輪の外側で状態を更新）
```

## MVP（Minimum Viable Product）の定義

**「編成 → 週送り → 結果 → 資金」の輪が一周する**ことだけをゴールにする。
面白さの検証はここで初めて可能になる。以下に**入れるもの／入れないもの**を明記する。

### MVP に入れる（これだけ作る）

| 要素 | MVP での範囲 |
|---|---|
| 冒険者 | 4〜6名を**固定データで**用意。ステータス6種と職業のみ。氏名生成・性格効果・加齢はまだ無し |
| クエスト | 2〜3件を**固定表示**。ランク・難易度・報酬・索敵要求値を持つ |
| 編成 | 4スロットにドラッグで配置。**前衛/後衛の区別はまだ無し** |
| 週送り | フェーズ1（索敵）＋フェーズ2（戦闘比率）を計算。**致死判定は簡易版**（HP0で「重傷」のみ、ロストは後回し）|
| 資金 | 所持金・週給引落し・報酬加算だけ |
| 画面 | 中央（編成）＋右（結果ログ）の2ペインで可。左ペイン・施設UIは後回し |
| セーブ | まだ無し（メモリ上のみ） |

### MVP に入れない（あとで足す）

加齢・成長・衰微 / 満足度と退団 / 相性・特性 / 不可逆障害・戦死 / 施設Lv / 顧問制度 /
ギルド格付け・Sランク / 治安（脅威度）/ セーブ・ロード / 氏名生成 / UI美装・音。

> これらは**すべて後から独立して足せる**設計になっている（→ 03 システム仕様）。
> だからこそ MVP 時点で完成度を上げすぎないことが重要。

## MVP 完成の判定基準

次がすべて満たされたら MVP 完成とみなし、機能追加フェーズへ進む。

- [ ] クエストを1つ選び、4名を編成できる
- [ ] 「次週へ」を押すと戦闘が解決し、勝敗・HP消費・報酬がログに出る
- [ ] 所持金が「報酬 − 週給」で正しく増減する
- [ ] 上記を**エラーなく複数週連続で**繰り返せる

## MVP 後の追加順（推奨）

小さく確認しながら1機能ずつ。前の機能が動いてから次へ。

1. 加齢・成長・衰微モデル
2. 満足度と退団（人事の緊張を追加）
3. 前衛/後衛の列システムと配置補正
4. 施設Lv投資
5. ギルド格付け・Sランク（勝利条件の実装）
6. 不可逆障害・戦死（喪失体験の実装）※コア体験の核なので丁寧に
7. 治安（脅威度）と敗北条件
8. 顧問制度・相性・特性
9. セーブ/ロード
10. 氏名生成・UI美装・音・演出
