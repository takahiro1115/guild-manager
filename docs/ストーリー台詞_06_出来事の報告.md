# ストーリー台詞 06：出来事の報告（草稿）

> **正本は「ギルド物語帳」（https://claude.ai/artifact/KgYoSK4u8JbTtaPHTVgdef）。** 2026-10-08、ユーザー判断。この md は2026-10-18時点の写し（物語帳の並び順で、場面ごとに書き出した。本文の見出しは1段下げた）。物語の設定・台詞を変えるときはページを直す。

> 2026-10-16 作成。**草稿**。月報の「主な出来事」の知らせ（緑の行など）を、人物に話させる台詞。書き方の約束は台詞 01〜05 と同じ。

**出し方（2026-10-16、ユーザー判断）**
- **部隊長の報告のあと**、同じ物語の小窓で続けて出し、そのあと月報を開く。「報告をとばす」で月報へ飛べる。
- その月の知らせは**全部話す**（数の上限なし）。
- 月報の「主な出来事」の行は**そのまま残す**（台詞は演出、月報は記録）。
- 並び：判断が要る知らせ（★）を先に、そのあと冒険者の出来事、手紙の順。
- 同じ月に、その知らせの**物語の場面**（台詞 01〜03）も出るときも、**出来事の報告を出す**（2026-10-16、ユーザー判断）。
  場面は月報のあとに出るので、出来事の報告は場面の見せ場を先に言わない**導入の一言**に替える（→ 台詞 06 の 7）。
  重なるもの：出撃できる部隊が2つ・3つになった（s01_squad2・s01_squad3）、深淵が開いた（s03_abyss）、イザベラの来訪（s02_visit）、
  交流戦の結果（s02_lost・s02_won・再戦）、王都の大会が開く（s02_tournaments）、派遣の教官の着任（s02_marguerite）、初めての入賞と依頼の始まり（s02_royal）、
  初めての年間1位（台詞 03 の 13）。初めてのG1優勝・初めての殿堂入りは、ふつうの台詞のままで食い違わない。
- 番人の撃破は部隊長の報告が話すので、出来事の報告には入れない。
- 施設が開いた知らせは、今の「施設が開いた台詞」（`facility_unlock_lines.csv`、大会の結果の小窓）をそのまま使う。ここには書かない。

**話す人**
- **アルベール**：研究・迷宮・秘薬の知らせ。お金と運営の話には興味が無い（手紙を渡されても「あなたに任せるわ」）。
- **ルミナ**：手紙や知らせを持ってくる・読み上げる役。森の20Fで救出したあとだけ。まだいないときは、ルミナの行を飛ばす（アルベールだけで成り立つように書く）。
- **イザベラ**：来訪のあと、手紙で（依頼人がイザベラのとき）。
- **冒険者本人**：冒険者の出来事。口調は部隊長の報告（`report_lines.csv`）と同じ約束で、**気質**（慎重・中庸・大胆）の台詞を基本にし、初期の3人（クラウディア・リナ・フィオナ）は専用の台詞を持つ。

**書き方**
- 1件は1ページ（台詞1〜3行。前に〔地の文〕を1行置いてよい）。
- ★の知らせ（このあとプレイヤーが判断した方がいいもの）は、最後に【画面へ】で行き先を添える（「📍 次は上の○○の画面で、…」になる）。【手引き】は付けない。
- 同じ知らせが何度も来るものは案を2〜3つ書き、月ごとに回す（乱数は使わない）。
- 副官は話さない。

**差し込み記号**（実装のときに埋める）
{フィールド}＝開いたフィールドの名前／{研究}＝研究の名前／{施設}・{Lv}＝施設の名前と段／{子}＝娘の名前・{母A}{母B}＝その母／{育て方}・{伸び}＝培養槽の育て方とその月の伸び（例「STR+2・VIT+1」）／
{名前}＝出来事の当人／{相手}＝相手の子／{後輩}＝面倒を見た後輩／{能力}＝ひらめきで伸びた能力／{金額}＝金額／{ギルド}＝引き抜きの話をよこしたギルド／{週}＝答えの期限の週数／
{スポンサー}＝スポンサーの名前／{依頼人}＝依頼人／{大会}・{順位}＝大会と順位／{日付}＝招待された大会の月と週／{二つ名}＝二つ名／{殿堂の理由}＝殿堂入りの理由
