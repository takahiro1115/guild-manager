## 4. 森の30Fでアルベールが示す方向（台詞 05 の顔見せ 1 に足す）

今の草稿の最後（「ルミナに、二度と手を出させないで」）のあとに、ルミナが寝たあとの研究室で、アルベールが副官にだけ話す1ページを足す案。
- 森だけでなく、**ほかの迷宮にも「主」がいる**こと（番人の結晶の記録から。名前はまだ言わない）。
- 主たちは、**ルミナを「鍵」として欲しがっている**らしいこと（何の鍵かは、アルベールにも分からない＝と言う）。
- アルベールは**ルミナを守る**。そのために、迷宮の底に眠る**古代エルフの都（理想郷）の記録**を調べる。副官には迷宮を深く進めてほしい。
- 真相（ルミナの生まれ・アルベールが預けたこと）は言わない。「理想郷」の言葉も、アルベールの研究の目的として出すだけにする（前兆4〈峡谷の50F〉の夢と、真相で回収）。
