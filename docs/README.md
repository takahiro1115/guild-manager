# 冒険者ギルドマネージャー（仮称）― 開発ドキュメント一式

Godot 4.7.2（.NET版）／.NET 9 SDK（プロジェクトのTargetFrameworkは `net8.0`）で開発する
経営シミュレーションの企画・設計文書。
**Git で管理し、開発しながら育てる**前提で作成。数値は全て暫定（叩き台）。

## 実プロジェクトの構成（2026年9月導入時点）

```
GuildManager/                  ← リポジトリルート
├── docs/                      ← このドキュメント一式（今見ているもの）
├── guild-manager.godot/       ← Godotプロジェクト（ビュー層）
└── GuildManager.Core/         ← 純C#クラスライブラリ（モデル層）
```

環境・バージョンの詳細と導入の経緯（.NET 9 SDKと`net8.0`ターゲットの関係など）は
`05_技術メモ.md` を参照。

## 読む順番

初めて見る人は `01 → 02 → 03` の順。実装に入るときは `05` と `06` を手元に、
数値をいじるときは `04` を開く。

## 開発の進め方（要約）

1. **Phase 0**：環境構築・Godot学習・2プロジェクト構成（Core分離）・Git開始
2. **Phase 1–2**：MVP（編成→週送り→結果→資金 が一周する骨組み）
3. **Phase 3**：機能を1つずつ追加（加齢→満足度→…→ロスト→治安）
4. **Phase 4**：バランス外部化・セーブ・UI美装・仕上げ

詳細は `02` と `06` を参照。

## 更新のルール

- 決定が変わったら `03` / `05` を直し、**理由をコミットメッセージに残す**。
- 遊んで出た数値調整は **`04` 側だけ**で行う（`03` には数値を書かない）。
- `04` は実装で CSV/JSON に書き出し、C# の Core が読み込む（`05` §3）。

## v1.0 からの主な決定（03 §0 の要約）

致死閾値のクランプ／満足度の改名（Satisfaction）／PAをステータス毎に／HP≤0経路の接続／
年齢帯の統一／UIスケール方針／職業Scout→Ranger改名、および未定義だった
個人CP式・ギルド格付け・経済スケール・列システム・相性/特性・疲労回復・治安モデルの新規定義。
