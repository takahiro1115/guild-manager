# docs/ ― 設計ドキュメントの索引

このフォルダは、冒険者ギルドマネージャー（仮称）の企画・設計文書の置き場所です。
**プロジェクト全体の概要・開発の進め方・現行バージョン（v2.0）の仕様要約は、
リポジトリルートの [`README.md`](../README.md) を参照してください。** このファイルは
docs/ 配下の各文書の役割を案内する索引に徹し、内容の要約は重複して持ちません。

## 読む順番

- 初めて見る人は `01 → 02 → 03` の順。
- 実装に入るときは `05`（技術メモ）と `06`（タスクリスト）を手元に置く。
- 数値を調整するときは `04_バランス表/` の CSV を開く。

## 更新のルール

- 決定が変わったら `03` / `05` を直し、**理由をコミットメッセージに残す**。
- 遊んで出た数値調整は **`04_バランス表/` 側だけ**で行う（`03` には数値を書かない）。
- `04_バランス表/` の CSV は C# の Core（`GuildManager.Core/Balance/`）が実行時に読み込む
  （キー欠落・パース失敗は例外。コード側にフォールバック値は持たない、→ `05` §3）。
- 実装を終えたら `06` の該当タスクを完了（`[x]`）にする。
