## 1. システム全体構想

- **タイトル:** 冒険者ギルドマネージャー（仮称）
- **エンジン:** Godot **4.2 以降**（C# / .NET 8）※ .NET 8 対応は 4.2 から。対象は PC（Win/Mac/Linux）。C# は Web 書き出し非対応のため Web 版は想定しない（→ 05）
- **解像度:** 論理 1920×1080 を基準。ウィンドウ拡縮は Godot の content scale で対応（→ §9・05）
- **設計方針:** モデル層（Godot 非依存の純 C# ライブラリ）とビュー層（Godot Node/UI）を完全分離。

### 1.2 時間モデル
- 1ターン ＝ 1週。1ヶ月 ＝ 4週。1年 ＝ 12ヶ月 ＝ 48週。
- 目標：20年（960ターン）で最高格付け Sランク到達。達成後エンドレスモードへ。
- 検算：20年 × 48週 = 960ターン。✓
- 期間設計の意図：初期メンバー1世代の稼働年数（稼働の中核は §3.0 の22〜34歳）では
  20年を走り切れず、必ず新人採用と世代交代が要る。「初期メンバーだけでは
  クリアできない」を加齢・強制引退（§3.7）だけで構造的に保証するための年数。

## 2. 冒険者データモデル

### 2.1 静的・基本属性

- **ID:** GUID
- **氏名:** 文字列（氏名ジェネレータ。MVP では固定名でよい）
- **年齢:** 整数 15〜40（§3.0 で上限到達時の扱いを定義）
- **職業（JobClass）:**
  - 重戦士（**Warrior**）：耐久・筋力特化、前衛適正高、ヘイト集中
  - 斥候（**Ranger**）：俊敏・索敵特化、前衛/後衛可、不意打ち防止 ※旧 Scout をリネーム
  - 魔導士（**Mage**）：魔力特化、後衛専任、範囲殲滅
  - 神官（**Cleric**）：精神・回復特化、後衛専任、致死回避・負傷軽減
- **性格（Personality）:** 質実剛健 / 合理主義 / 好漢 / 慎重派（効果は §5・§3 に接続。MVP では未使用でよい）

### 2.2 能力値（実効値 1〜100）

STR / AGI / END / MAG / SCT / LDR の6種。各ステータスの役割は v1.0 のとおり。

- **潜在能力 PA：ステータス毎に `PA_STR`…`PA_LDR` の6値を持つ（各 1〜100）。** 実効値は対応する PA を上限に成長する。
- **総合PA** ＝ 6つの PA の平均（採用試験・スカウト評価など「素質の高さ」を1数値で見たい箇所で使用）。
- 生成時の関係：新人はステータス実効値 < PA。序盤は伸びしろ、加齢で PA 自体が低下していく（§3）。

### 2.3 動的・コンディション属性

- **現在HP / 最大HP：** `最大HP = END×2 + 50`（END 1〜100 → 52〜250）
- **疲労度（Fatigue）:** 0〜100。100 で出撃不可。回復ロジックは §3.5 で定義
- **満足度（Satisfaction）:** 0〜100。50未満でサボタージュ傾向、20未満で移籍・退団検討（§5）
  - ※ v1.0 の「Morale」を改名。戦闘中の一時的な士気（Morale）は post-MVP の別フィールドとして予約
- **負傷状態（InjurySeverity）:** なし / 軽傷（全治1〜2週・該当能力-10%）/ 重傷（全治3〜8週・出撃不可・-30%）/ 不可逆障害（完治不能・恒久低下）
- **契約週給（WeeklyWage）:** 毎週引落しの基本給（→ BAL: 経済/週給基準）

## 3. 加齢・成長・衰微モデル

### 3.0 年齢帯の統一定義（v1.0 の境界不整合を解消）

| 年齢帯 | 範囲 | 主な挙動 |
|---|---|---|
| 成長期 | 15〜21 | 成長率 1.5倍、フィジカル急成長、自律成長ロール有 |
| 全盛期 | 22〜27 | 上下動が最も安定。昇給要求が発生しやすい |
| 円熟期 | 28〜34 | 精神系（LDR/SCT/MAG）維持可。年1回フィジカル衰微 |
| 限界期 | 35〜40 | 衰微が年2回・低下量拡大。自然治癒が2倍遅い。引退傾向 |

> §5.1 の出場機会ペナルティ対象年齢もこの表に合わせ **22〜27歳**に統一（旧「22〜28」を修正）。→ BAL: 満足度/出場機会

### 3.1〜3.4 成長・衰微の数値

- 成長率倍率、自律成長ロール確率、衰微の実行タイミング（週）・対象ステータス・低下量は **すべて → BAL: 加齢** に集約。
- 衰微は「該当年齢帯の指定週に、STR/AGI/END からランダムに1〜2項目を恒久低下」。低下量は年齢帯で変わる（→ BAL: 加齢/衰微量）。

### 3.5 疲労回復（v1.0 で未定義 → 新規）

- 出撃した週：クエスト難易度に応じて Fatigue 加算（→ BAL: 疲労/出撃加算）。
- 非出撃（待機）の週：Fatigue を一定量回復（→ BAL: 疲労/待機回復）。
- 施設補正：宿舎・医務室 Lv により回復量に倍率（→ §6）。
- Fatigue 100 到達で当該冒険者は「過労」フラグ、次週まで出撃不可。

### 3.6 負傷回復処理（v1.1で欠落判明・新規追加）

**発覚の経緯:** Phase 2 のMVPを実際にプレイしたところ、重傷になった冒険者が一度も回復せず、詰み状態のまま出撃させ続けられることが判明した。§2.3で負傷の全治週数（軽傷1〜2週／重傷3〜8週）をデータとして定義していたにもかかわらず、それを消化して治す処理がv1.0・v1.1のどちらにも存在していなかった。

- 負傷した週に、その負傷の全治週数を `InjuryWeeksRemaining` としてランダムに決定し保持する（軽傷1〜2週、重傷3〜8週の範囲で）。
- 毎週の決算処理で、負傷している全冒険者の `InjuryWeeksRemaining` を1減らす。
- 0に達したら `Injury = None` に戻し、`CurrentHP = MaxHP` として全快させる。
- **出撃制限:** `Injury == Severe` の間は編成画面で選択できないようにする（MVPのUIには未実装だったため、Phase 2の修正で追加）。
- 不可逆障害（Permanent）はこの処理の対象外（そもそも完治しない。仕様書 §2.3・§4.3参照）。

### 3.7 年齢上限到達の扱い（旧§3.6を繰り下げ）

- 40歳の年の年末（第48週決算）に**強制引退**。以後は顧問として再任用可能（§7）。
- 限界期は毎年「引退勧告（肩たたき）」を提示でき、受諾率は年齢とともに上昇（→ BAL: 加齢/引退勧告受諾率）。

### 3.8 レベルアップ制度（v1.1で新規追加：加齢とは独立した成長経路）

**追加の経緯:** §3.1〜3.7の加齢モデルは年齢帯に応じた受動的な成長・衰微のみを扱い、
「クエストに出て経験を積む」という能動的な成長手段が無かった。プレイして出た要望により、
加齢による変化（AgingSystem）とは別に、クエスト参加による成長経路として新規追加した。

- **経験値の獲得:** クエストに参加した冒険者は、成功・失敗を問わず経験値を得る
  （→ BAL: レベル/経験値獲得量。現状はクエストの `QuestDifficulty` をそのまま採用する仮値）。
  ただし **今回の遠征でダウンした者は無報酬**（ユーザー決定）。ここでの「ダウン」は
  現在のMVP簡易実装では「フェーズ2のHP消費で現在HPが0に達したこと」を指す
  （§4.2の本来の個別ダウン判定はまだ未実装のため、その代用）。
- **レベルアップの効果:** 経験値が閾値に達するとレベルが上がり、ランダムに選ばれた
  1ステータスの**実効値とPA（潜在能力）の両方**が同じ量だけ伸びる
  （→ BAL: レベル/上昇量。現状は仮値）。PA自体を伸ばすことで、成長期（15〜21歳）を
  過ぎた冒険者でも経験を積めば伸びしろが増え、実質的に成長を続けられる。
- **レベル上限:** 上限を設ける（→ BAL: レベル/上限。現状は仮値）。上限到達後は
  経験値を貯めても意味を持たせず、獲得経験値をその都度切り捨てる。
- **衰微との関係:** レベルアップで伸びたPA・実効値も、AgingSystemの恒久低下（§3.1〜3.4）から
  特別扱いしない。AgingSystemはPA/実効値を出自を区別せず一律に減算するため、
  「レベルで伸びた分だけ衰微を免れる」といった例外は設けない（ユーザー決定）。

## 4. クエスト・遠征解決エンジン

「次週へ」実行時、派遣中の各パーティに対して以下の順で解決する。

### 4.0 クエストの定義（スケール確定）

各クエストは以下を持つ。**難易度・索敵要求・報酬はランクに紐づく**（→ BAL: クエスト）。

- **ランク:** E / D / C / B / A / S（ギルド格付けと同じ体系）
- **QuestDifficulty:** 1〜100 の整数（ランク帯ごとの範囲は → BAL: クエスト/難易度レンジ）
- **QuestScoutRequirement:** 1〜100（SCT と同スケール。→ BAL: クエスト/索敵要求）
- **報酬（ゴールド）／期限（週）／放置危険度**

### 4.1 フェーズ1：索敵・遭遇判定

```
PartyScout = max(SCT) + 平均SCT×0.3 + 隊長LDR×0.2
ΔS = PartyScout − QuestScoutRequirement
Roll = Random(1,100)
```

- `Roll ≤ clamp(15+ΔS, 1, 99)` → 奇襲成功：パーティ戦闘力 +30%
- 上記超〜`clamp(80+ΔS, 1, 99)` → 通常交戦：補正なし
- それ超 → 不意打ち：敵戦力 +30%、後衛の被弾ウェイト上昇（§4.3）

> v1.1 で **境界を 1〜99 にクランプ**（ΔS が極端でも帯が消えない・逆転しないように）。

### 4.2 フェーズ2：戦闘比率と個別ダウン判定

**個人CP（v1.0 で未定義 → 新規定義）:**

```
個人CP = ( STR×wSTR + AGI×wAGI + END×wEND + MAG×wMAG + LDR×wLDR )
         × 職業配置補正(職業, 配置)
         × (現在HP / 最大HP)
```

- 重み `wXXX` と職業×配置（前衛/後衛）の補正は → BAL: 戦闘/CP重み・配置補正。
- SCT は CP に含めない（索敵フェーズ専任）。これで全ステータスに役割が付く。

```
PartyCP = Σ個人CP × 索敵補正 × (100 − 平均疲労度)/100
EnemyCP = QuestDifficulty × 3.0        （→ BAL: 戦闘/敵CP係数）
Ratio   = PartyCP / EnemyCP
```

**勝敗と基本損耗（HP消費%）:**

| 結果 | 条件 | 任務 | HP消費 | 個別ダウン判定 |
|---|---|---|---|---|
| 完全勝利 | Ratio ≥ 1.8 | 達成 | 5〜15% | 無し |
| 辛勝 | 1.0 ≤ Ratio < 1.8 | 達成 | 20〜45% | 無し |
| 苦戦敗退 | 0.6 ≤ Ratio < 1.0 | 失敗 | 40〜70% | 各員が確率でダウン → §4.3 |
| 戦線崩壊 | Ratio < 0.6 | 壊滅 | — | 各員が高確率でダウン → §4.3 |

**個別ダウン判定（v1.0 の「HP≤0 経路」欠落を解消）:**

- 損耗%を各員の現在HPに適用したうえで、苦戦敗退・戦線崩壊では各員が「ダウン」ロールを行う。ダウン確率は結果ランクで変わる（→ BAL: 戦闘/ダウン確率）。
- **AGI が高い者はダウン確率が下がる**（＝逃走成功の表現。v1.0 の「AGI 逃走成功率」をここで接続）。
- ダウンした者だけがフェーズ3（致死判定）へ進む。ダウンしなければ重傷止まり。

### 4.3 フェーズ3：負傷・致死判定（低確率ロスト仕様）

ダウンした冒険者に対して判定する。

```
SurvivalThreshold = clamp( END + 神官MAG×0.4 + 隊長LDR×0.2 , 5 , 90 )   ← v1.1 でクランプ追加
PermanentBand     = 20   （→ BAL: 戦闘/不可逆帯幅。調整可）
Roll = Random(1,100)
```

- `Roll ≤ SurvivalThreshold` → **生存**：HP1で踏みとどまり重傷（全治3〜6週）
- `SurvivalThreshold < Roll ≤ SurvivalThreshold + PermanentBand` → **不可逆障害**：永続デバフ。引退・顧問化へ誘導
- `Roll > SurvivalThreshold + PermanentBand` → **戦死**：キャラクター完全ロスト

> **修正の要点:** (1) 閾値を最大90にクランプしたので、どんなに硬い前衛でもロストは 0% にならない。(2) 範囲方式に一本化し、v1.0 の「70%/30%の割り当て」注記は廃止（範囲と矛盾していたため）。ロストの希少さは「フェーズ2でそもそもダウンしにくい」ことで担保する設計に変更。

### 4.4 フェーズ4：治安連動処理

- 放置された討伐クエスト1件につき街の **脅威度 +2〜5%**（→ BAL: 治安）。
- クエスト達成で該当地域 **-10〜15%**。
- 脅威度 75% 超で市場素材価格が高騰し、月次助成金が 50% カット。
- **地域モデル:** MVP は**単一の街（脅威度1値）**。複数地域は post-MVP（→ §11 未決事項）。

## 5. クラブ運営・人事マネジメント

### 5.1 満足度（Satisfaction）変動ロジック

毎週日曜の決算時に増減（各係数 → BAL: 満足度）。

- 出場機会：22〜27歳が「4週連続で遠征なし」なら毎週 -5
- 賃金妥当性：実力ランクに対し週給が適正値の80%未満なら毎週 -8
- 人間関係：相性「険悪」（→ §5.3）のメンバーと同パーティ出撃で -10
- 勝利・功績：Bランク以上クエスト達成で +10
- 仲間ロストの余波：同パーティの死亡で一律 -30 ＋確率でトラウマ特性付与（→ §5.3）
- 自然回復：酒場 Lv により毎週 +（→ §6）

### 5.2 契約交渉と退団

- 満足度20未満でインボックスに「昇給要求」または「移籍検討」警告。
- 2週以内に昇給（週給 1.5〜2.0倍提示）またはボーナスを行わなければ自発的に契約解除・他都市へ移籍（消滅）。

### 5.3 相性・特性システム（v1.0 で参照のみ → 新規定義）

- **相性値:** 冒険者ペアごとに -100〜+100 を保持。ゲーム開始時に生成（乱数 ＋ 性格相性）。同パーティ出撃の成否で漸増減。閾値「険悪 = -40以下」「盟友 = +40以上」（→ BAL: 相性）。
- **特性（Trait）:** 少数の列挙型から開始（例：豪胆／トラウマ／師匠肌 等）。効果は満足度・成長・戦闘に小補正。**MVP・序盤機能では未実装、後から追加**。

## 7. 引退とセカンドキャリア（顧問制度）

- 退職金（週給 × 12週）一括支給で顧問として再任用。
- **教官（Trainer）:** 訓練場に配置。訓練中の若手へ、自身の秀でたステータスを伝授（確率・効果 → BAL: 顧問/教官伝授）。
- **スカウト（Scout Master）:** 新春採用試験で総合PA 75以上の有望新人応募率 +25%。
- **作戦参謀（Advisor）:** 作戦資料室に配置。勝率計算精度を上げ事故率を抑制。
- **保有枠との関係（新規決定）:** 顧問は宿舎の保有枠（現役枠）を**占有しない**。顧問は各施設の専用スロット（教官枠 等）にのみ入る。

## 8. 勝敗判定条件

### 8.1 ギルド格付け（v1.0 で未定義 → 新規：勝利条件の根幹）

- ギルドは **名声（Reputation）** 整数を持つ。クエスト達成で加算、失敗・ロストで減算（値 → BAL: 格付け/名声増減）。
- 名声の累積閾値でランクが上がる：**G → F → E → D → C → B → A → S**（閾値 → BAL: 格付け/ランク閾値）。
- ランクは「受注可能クエストの最高ランク」と「助成金額」に影響。

### 8.2 勝利条件
