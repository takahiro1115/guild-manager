## 1. 初期配置冒険者（古参3名：固定データ）
- SampleData.cs の初期配置を 4名 → 3名 に変更。
  - 冒険者A（古参・前衛）: 戦士（Warrior）、円熟期（28歳前後）。即戦力。
  - 冒険者B（中堅・遊撃）: 斥候（Ranger）、全盛期（23歳前後）。索敵・探索の要。
  - 冒険者C（中堅・後衛）: 神官（Cleric）または魔導士（Mage）、成長期後半〜全盛期（21歳前後）。

## 2. 初期採用イベント（第1年・第1週 即時発生）
- 03 §2.4 の例外規定「1年目は新春採用試験なし」を改訂。
- 第1年・第1週（ゲーム開始直後）にチュートリアル採用試験を即時発生させる。
  - 候補者リスト: 新人4〜5名を提示。
  - 採用枠: 3名を採用（初期契約金ボーナス等で3名契約可能とする）。
  - 以後の新春採用試験は従来どおり「各年の第1週（第49週、第97週…）」に年1回発生。

## 3. 到達状態（第1週 出撃準備フェーズ）
- 現役ロースター: 古参3名 ＋ 新人3名 ＝ 計6名。
- 出撃判断: 4人枠に対して6名が存在するため、第1ターンから「誰を出撃させ、誰を休ませて育てるか」のマネジメントが発生する。
