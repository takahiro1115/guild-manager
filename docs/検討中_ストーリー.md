## 0. ねらいと役割分担

- 副官（プレイヤー）は直接話さない。
- 冒険者が8年で去り、娘の代へ移っていくゲームなので、**変わらずそばにいる人物**（長命の3人）を物語の軸にする。
- 大迷宮の最初のフィールド（翠緑の原生林）の20Fまでを、プレイヤーを導くチュートリアルの物語にする。

| 人物 | 役割 | 教えること |
|---|---|---|
| **アルベール**（ギルドマスター） | 研究と迷宮（生体コード）にしか興味が無く、ギルドの運営には無知 | 研究・迷宮・秘薬 |
| **ルミナ**（副官の助手） | **狂言まわし**。外の世界もギルドの仕組みも知らないので、プレイヤーが疑問に思うことを代わりに質問する（例「教官を置いたらどうなるんですか？」）。アルベールとやり取りする | 教えない（聞く側） |
| **イザベラ**（ライバル、よそのギルドのマスター） | 不老の魔女。アルベールの魔法学園時代の級友。勝負を吹っかけてきて、結果的にギルドの運営を教えてくれる | 施設・大会・依頼・教官など、ギルドの運営 |

## 1. ルミナ（副官の助手、エルフの少女）

### 決めたこと（2026-10-07〜08、ユーザー判断）

| 項目 | 決めたこと |
|---|---|
| 名前 | **ルミナ**（「光」の響き。生体コードに触れると光る前兆と重なる） |
| 登場の時期 | **森の10Fのボスで予告、20Fのボス（甲殻の大猪）で救出**。20Fまでの道のりをチュートリアルの目的にする |
| 10Fでの予告 | **助けを求める声と痕跡**：10Fのボスを倒した部隊が、奥からのかすかな声を聞き、引きずられた跡とエルフの髪飾りを持ち帰る。アルベールは髪飾りを見て顔色を変え、20Fへ急ぐ理由になる |
| 出自 | 表向きはエルフの里で育った娘で、迷宮で捕らわれていた。実は古代エルフの母権社会（失われた理想郷）の血を引いていた、と後で明かす。依頼人「エルフの里」とつながり、生体コードの本筋の謎にもなる |
| 立場と関係 | **戦わない職員（副官の助手）**。冒険者の名簿に入らないので、引退・除籍で失わない。アルベールとは**保護者と弟子**（母と娘に近い）。恋愛や嗜好の対象としては描かない。「冒険者になりたいが、アルベールが許さない」という火種を持たせる。ライバルにも面倒を見てもらう |
| 役割 | **狂言まわし**：無知なので、プレイヤーに必要な説明を質問で引き出す。アルベールとやり取りする。副官の決定を代わりに口にしすぎない（プレイヤーの選択を奪わない） |
| 性格 | **素直で真面目、ときどき鋭い**。丁寧語で副官を慕う。アルベールの暴走には真面目に困り、ときどき核心を突く一言でつっこむ |
| 呼び方 | 副官を「**副官さま**」、アルベールを「**マスター**」と呼ぶ（親しくなると、ときどき「アルベールさま」） |
| 古代の血を明かす時期 | **各フィールドの50Fで前兆を見せ、峡谷を制したとき（100F）に、深淵の最深部へ挑む前としてアルベールが自ら打ち明ける**（→ §4）。アルベールは10Fの髪飾りの時点から気づいているが黙っている |
| アルベールが黙っていた理由 | **3つが重なる**：①守るため（古代の血が知られれば王都や学院に狙われる。「普通の子」として生きさせたかった）／②過去の親友とのつながり（髪飾りは、政略結婚で引き裂かれた親友〈女勇者と女聖女〉の形見。ルミナはその系譜につながり、口に出せなかった）／③研究のため（自然に目覚めていく様子を観測したかった）。明かされたときに「守りたかった」と「観測したかった」の両方を認めるのがドラマになる |

**古代の血の前兆（各フィールドの50Fのボスを倒したとき。2026-10-08、ユーザー判断）**

フィールドは並行して進む（森の10Fで洞窟が開き、4つのフィールドの20Fで深淵が開く）ので、前兆は各フィールドの50Fに置く。
シミュレーターの目安は森3.9・洞窟4.3・廃墟5.0・峡谷5.6年目で、難しさの順に自然に並ぶ。順番が入れ替わっても崩れないように、各前兆は前の前兆を待つ（先に50Fを倒していたら、前の前兆のすぐあとに起こす）。

| フィールド | 前兆 |
|---|---|
| 翠緑の原生林 | 生体コードの結晶に触れると淡く光る |
| 嘆きの鍾乳洞 | 歌う水妖の歌を、古い言葉として聞き取る |
| 忘却の古代廃墟 | 古代文字が読める。廃墟の守護者が彼女に跪く |
| 焦熱の峡谷 | 夢で理想郷（古代エルフの母権社会）の記憶を見る |
| 深淵の特異点 | （アルベールが打ち明けたあと、深淵の90F台）特異点の支配者が、彼女の本当の名「ルミナリエ」を呼ぶ。打ち明けられたことが確かめられる |

## 2. イザベラ（ライバル、よそのギルドのマスター）

### 決めたこと（2026-10-08、ユーザー判断）

| 項目 | 決めたこと |
|---|---|
| 名前・種族 | **イザベラ**。**不老の魔女**（人間だが魔術で年を取らない。エルフばかりにならない。元冒険者にしない＝加齢の心配が無い） |
| 素性 | **アルベールの魔法学園在籍時の級友** |
| 口調 | **お嬢様口調の高飛車**（「〜ですわ」「〜して差し上げますわ」）。「〜わ」「〜ね」で話すアルベールと口調がかぶらない |
| アルベールへの思い | アルベールをライバル視しているが、**実はアルベールのことが好きなツンデレ**。アルベールがまた迷宮の探索を始めたことを嬉しく思っているが、素直に応援できないので、いちいち勝負を吹っかけてくる |
| 再戦 | **季節に1回、こちらから申し込める**（🏆 大会のタブに「イザベラに交流戦を申し込む」。月のはじめに決め、大会と同じく出場者はその月は出撃しない。申し込まなければ何も起きない） |
| 初めて勝ったときのご褒美 | **教官の派遣**：イザベラが自分のギルドの引退者を、教官として数か月貸してくれる。自分のギルドに引退者が出る（2年目の年末）前に、教官の仕組みを教えられる（ルミナ「教官を置いたらどうなるんですか？」） |
| 2勝目以降のご褒美 | **賞金と機嫌（G2並み）**：勝てば1,000G・マスターの機嫌+8（王都大会の優勝と同じ）。負けても無し |
| 派遣の教官 | **6か月・自分の主力並み**：派遣されるのは白百合の杖の元冒険者で教官の**マルグリット**（落ち着いた物腰）。能力はそのときの自分のギルドの主力と同じくらい。6か月で帰るので教官の大切さが分かり、初めての引退者を教官にする楽しみにつながる |
| 相手の強さ | **少し上で、再戦ごとに強くなる**：最初は40Fに着いたギルドの主力より少し上（初回に勝てるのは3〜4割）。「まだまだですわね」を見せつつ、育てれば勝てる。イザベラのギルドも年ごとに育つ |
| ギルド | **白百合の杖**（魔女の杖と白百合。アルベールへの秘めた想いがにじむ）。**王都の名門で、大会と王都の仕事で稼ぐ**：迷宮には潜らない商売上手（「迷宮など危険なだけですわ」）。迷宮と研究のアルベールと対になり、運営を教える立場に説得力が出る |
| 得意な部門 | **魔**。王国魔導祭の常連で、交流戦でも魔の試合がいちばん手強い |
| 看板の冒険者 | **セシリア「氷華」**：冷静な天才の魔導士（イザベラの秘蔵っ子）。表情を崩さず、自分のギルドの子に負けたときだけ少し悔しさを見せる。交流戦の魔で立ちはだかり、王国魔導祭で何年もそびえる「去年の決勝で負けたあの子」。この子も年を取り、いずれ引退する（看板が代替わりする） |
| 交流戦の剣の相手 | **ブリジット**：熱血の剣士。うるさいくらい元気で、勝っても負けても「もう一回！」。イザベラに振り回されつつ憧れている。自分のギルドの剣士と友情が生まれやすい |
| 交流戦の技の相手 | **ニナ**：飄々とした弓使い。いつも眠そうでつかみどころが無いが、狙いは外さない。ルミナによく変なことを教える |
|（3人の色） | 冷静なセシリア・熱血のブリジット・飄々としたニナ。3人とも年を取り、いずれ引退して代替わりする |
| 教える理由 | 勝負に負けたら「仕方なし」と言いつつ、ギルドまで来ていろいろと教えてくれる。勝っても「このままじゃ放っておけない」と教える。ルミナの面倒も見る |
| 来訪のきっかけ | **森の40Fに到達したとき**（40Fのボスの撃破。討伐だけでは届きにくく、手前で解析〈迷宮調査〉のチュートリアルが入るので、それを越えてから）。「最近また大迷宮に潜らせているそうですわね？」「わたくしの冒険者と、実力を試してみませんこと？」「もし勝てたら、ギルドの運営を教えて差し上げてもよくってよ」。**大会はここから開く** |
| 最初の勝負 | **交流戦＝1対1の3本勝負**（剣・魔・技を1試合ずつ、2勝で勝ち）。大会の3部門をそのまま教えられる。**負けても再戦でき、勝敗にかかわらず助言は始まる**（負けたら「まだまだですわね。……このままでは放っておけませんわ」、勝ったら「し、仕方ありませんわね」）。ツンデレがよく出る |
| 教えること | **施設とギルドの運営**（施設・大会・依頼・教官・顧問・採用など）。ルミナの運営の質問にはライバルが答え、研究の質問にはアルベールが答える |

### 今の仕組みとのつながり
- 施設を大会の成績で開く（§0.82）は、「勝負に勝つたびにライバルが運営を教えてくれる」と読める。
- 段3のライバルギルド（`docs/検討中_大会と育成の栄光.md` §5）の、最初の顔になる。
- 依頼人の「魔導学院」は、アルベールとライバルの母校にできる。

## 3. 20Fまでのチュートリアル

### 決めたこと（2026-10-08、ユーザー判断）
- **ペース**：実際に遊ぶと、森の序盤には1年目の春のうちに届いた（シミュレーターの10F＝1.1年目・20F＝1.7年目は機械的な方針のため遅い）。バランスは変えない。チュートリアルは**1年目の春（春1〜春3の月）**に収まる前提で組む。
  出来事は日付ではなく**きっかけ**（ボスの撃破・扉前の撤退など）で起こすので、遅いプレイヤーでも順番は崩れない。
- **教え方**：**要るときに1つずつ**。その機能が要る瞬間に短い会話を出し、「その画面へ」のボタンを付ける。今やることは「ギルドの手引き」の欄にチェックリストで残す。強制はしない。
- **まだ教えていない機能は隠す**：タブ・ボタンは物語で教えるときに現れる。
- **飛ばし**：**初回のプレイは飛ばせない**（物語と一体）。**クリア後**の新しいゲームでは、始めるときに「物語と手ほどき あり／なし」を選べる。なしなら全機能を最初から開き、ルミナの救出など物語の山場だけ残す。
- **序盤は大会も依頼も無い**：大会は**ライバルの来訪（迷宮の節目）から開く**。
- **依頼は大会の結果で来る**：どこかの大会で**初めて入賞（ベスト4）**すると王都で名が知られ、次の季節のはじめから依頼が届き始める。
- **最初の訓練所**：交流戦のあと、勝敗にかかわらず**ライバルの助言で開く**（得意な子に合わせて1つ）。2年目のはじめの副官の救済（§0.82）はやめる。
- 20Fまではルミナがいないので、アルベールが新任の副官に話しかける形になる（短いので許容する）。

### ゲームの決まりが変わる点（実装のときに仕様書 03 に章を足し、シミュレーターで確かめる）
- 大会の暦を、ライバルの来訪（迷宮の節目）から置く。
- 依頼（§0.64）は、初めての入賞までは届かない。依頼の報酬は経済の大きな柱なので、序盤のお金の手応えが変わる。
- 交流戦（季節に1回の申し込み・1対1の3本勝負・初勝利で教官の派遣）を足す。
- 最初の訓練所はライバルの助言で開く。救済（`FacilityUnlockSystem.CheckRescue`）を撤去する。
- 施設が開いたときの演出の「副官の提案」は、副官が話すことになるので「**ライバル（イザベラ）の助言**」に替える（宿舎・酒場・冒険者支援室・作戦資料室）。
- クリアの年・最初のG1の年・施設のLv5が開く年がどれだけずれるかを、シミュレーターで確かめる。

## 4. 真相とエンディング

### 決めたこと（2026-10-08、ユーザー判断）

| 項目 | 決めたこと |
|---|---|
| ルミナの正体 | **引き裂かれた親友二人（女勇者と女聖女）の娘**。二人が古代エルフの秘術で授かった「女性同士の子」。政略から守るため迷宮に封じられた。アルベールの秘薬（魂魄融和）は、ルミナを生んだ秘術を取り戻す研究だった。**髪飾り・親友・秘薬・理想郷が一本につながる** |
| 明かす場面 | **峡谷を制したとき（100F、目安14年目）（または深淵の90Fのボスの撃破の早いほう、→ §5）、深淵の最深部へ挑む前に、アルベールが自ら打ち明ける**（深淵は2年目ごろから開いているので「深淵に入る前」ではなく「最深部へ挑む前」）。「この先は、黙ったまま連れていけないわ」。守りたかったことと、観測したかったことの両方を認める（アルベールの誠実さが出る）。深淵では支配者がルミナの本当の名を呼び、打ち明けられたことが確かめられる |
| 理想郷の結末 | **復元しない。「理想郷はもうここにある」**：深淵100Fで理想郷を復元できる力を手にするが、アルベールは使わない。世代を重ねた母娘や殿堂の子たちを見て、このギルドこそが理想郷だと気づく。遊んできた育成と別れが、そのまま答えになる |
| ルミナの結末 | **アルベールに許されて、初めて冒険者として迷宮へ出る**（「冒険者になりたい」の火種をここで回収する） |
| イザベラの結末 | 祝宴に来て悪態をつきつつ、**最後に一言だけ素直な気持ちを口にする** |
| 親友二人の名前 | **勇者リディア**（凛とした剣の人）と**聖女セラフィーナ**（祈りの人）。どちらもエルフ |
| ルミナの本当の名前 | **ルミナリエ**。髪飾りに刻まれていたが、里は前半しか読めず「ルミナ」と呼んだ。深淵で支配者が全部を呼ぶ。今の名を捨てずに済む |

### つなぎ合わせ（案。物語を書くときに確かめる）
- ルミナは数百年、迷宮に封じられて時が止まっていた。生まれたばかりの姿で封じられ、封印が十数年前に緩んで外に出たところを、エルフの里に拾われて育てられた（「表向きは里の娘」）。迷宮の呼び声に引かれて戻り、20Fで捕らわれた。
- 親友二人はエルフ（ルミナがエルフであることと合わせる）。アルベールとは学園の頃からの仲で、イザベラも二人を知っている。
