# バランス・シミュレーター（balance_sim）

`GuildManager.Core` の計算と週次決算をそのまま動かして、要求値・成長・経済の手応えを数字で確かめるための道具。
ゲーム本体とは独立したコンソールアプリで、Godot もセーブデータも使わない。

## 使い方（リポジトリ直下で）

```bash
dotnet run --project tools/balance_sim -- static
```

| モード | 出すもの |
|---|---|
| `anchor` | 要求値（討伐・護衛・隠密・解析・走破）と、§0.47の目安部隊（全能力S）の値を並べる |
| `static` | 全能力Sの4人部隊（装備なし）が倒せる最深ボス（解析なし／完全解析）、1F→100Fの週数、1週ごとの進軍 |
| `door` | その階層のボスを倒せる程度の部隊が、扉前まで潜る週数（手前の区間は完全解析） |
| `ideal` | PA60／80／100 の新人1名を18歳から理想的に育てた場合の、火力の加重平均の伸び |
| `game 回数 最大週数` | 通しのシミュレーション。機械的な方針のプレイヤーで森のボスを何週目に倒せるか、年ごとの主力の強さ |
| `game 回数 最大週数 free` | 同・お金の制約を外す（成長と要求値だけで進める速さを見る） |
| `game 回数 最大週数 frugal` | 同・装備の購入と施設の建設をしない（節約した場合の資金繰りを見る） |
| `game 1 60 trace` | 同・1週ごとの所持金・任務・HP・扉前の判断を出す |
| `campaign 回数 最大週数` | 5フィールドを深淵100F（クリア、→ 03 §8.2）まで回す。フィールドごとの節目ボス（10F・20F・50F・100F）を初めて倒した年、クリアした年、ボス撃破数の推移、秘薬で生まれた娘の数。例：`campaign 10 1440`（30年） |
| `campaign 回数 最大週数 nosf` | 同・魂魄融和の秘薬を使わない |

`game` モードの最後に、最初の48週の「お金の出入り」（項目ごと・1週あたり）と、各年のはじめの現役人数を出す。

バランス値は `docs/04_バランス表` の CSV（ビルド時に出力フォルダへコピーされる）から読む。
値を変えて比べたいときは、CSV を直してから実行し直す。

## 通しのシミュレーションの方針（プレイヤー役）

- 主力：狙うボスに合わせて、火力上位8名から4名の組を総当たりで選び（ギミック込みの火力÷要求火力が最も高い組。即死級の備えが半分未満の組は避ける。§0.68）、森の次のボスへ潜行。
  扉前は、着いた週のうちに Core が構え「標準」で判断する（§0.69）。扉前まで潜ったことがあり今の解析では火力が届かないボスには、潜り直す前に主力で迷宮調査をする
- 勝ち目が無い間は、主力で迷宮調査・採取をして解析と収入・機嫌を保つ
- 2・3枠目：残りの冒険者で迷宮調査（解析が完全でなければ）→ 採取
- 待機者は伸びしろの大きい訓練施設へ（割り振りは月のはじめだけ。月の途中は訓練生を出撃に回さない、§0.70）。施設は訓練所を順に建てる。遺物は鑑定して、良い装備は着せ、残りと素材は売る。余裕があれば店で装備を買う
- 採用試験では PA の高い順に、所持金に余裕があるだけ雇う（現役12名まで）

研究・参謀・宿舎の拡張は使っていない。2つ目以降のフィールドにも行かない。人間のプレイより遅めに出る前提で読む。

## campaign モードの方針（2026年10月、→ 03 §0.60）

`game` の方針に次を足したもの。

- 狙うボス：開いているフィールドの次のボスのうち、要求火力が最も低いもの（深淵を開く各フィールドの20Fも自然にこの順で倒す）
- 教官：引退者を、空いている訓練施設の教官に就ける（施設が扱う能力の合計が高い順）
- 研究：所持金が「費用＋3000G」以上あれば、済んでいない研究を順に済ませる。研究に要る素材と紅玉鉱石は売らずに残す
- 施設：訓練所に加えて宿舎・医務室も建てる。Lv3→4では専門を選ぶ（訓練施設は精鋭、オプション `rivalry` で切磋琢磨。§0.76）
- 秘薬：培養槽が空いていて所持金に余裕があれば、相性100のペアのうち総合PAの合計が最大の組に処方する（娘の職業は強い方の親、紅玉鉱石があれば触媒に）
- 霊薬（§0.61）：24歳以下の上位6名のうち、火力の重みが最も伸びる霊薬を1週1本飲ませる。霊薬の素材も売らずに残す
- 店（§0.61）：上位6名について、入荷している品から伸びの最も大きいものを1週1点買う（`game` モードは1Gあたりの伸びで選ぶ）
- 備え：買い物・研究・霊薬・秘薬には、年度末に満期を迎える者の退職金の見込み＋週給4週分＋3000Gを残して使う（残さないと退職金が重なって破産する）

- 待機中の過ごし方（§0.73）：既定は全員が「研究を手伝う」。研究は研究の手伝いで割り引いた額で払う（結果の行「研究の手伝いで割り引いた額」。自主練の比較はオプション `selftrain`・`selftrainall`）

`campaign 回数 最大週数 noelixir` で霊薬を使わない比較ができる。参謀・スカウトは使わない。

## 依頼と迷宮の異変（2026年10月、→ 03 §0.64）

campaign は既定で依頼を受ける。迷宮の異変は Core の週次決算で起きるので、どのモードでも入る。

- 撃破：主力が狙っているボス（要求火力の最も低い次のボス）のときだけ受ける
- 完全解析：受ける。2・3枠目の迷宮調査は、受けた完全解析の対象を先に調べる
- 納品：在庫が揃っているときだけ受けて、すぐ納める（素材を売らずに溜めると序盤の資金繰りが詰まる）
- 献上：現役が8名以上いて、上位4名以外に条件を満たす者がいるときだけ受け、その中で最も弱い者を譲る
- 遺物の鑑定は、週給4週分＋500Gを残せるときだけにした（依頼の報酬の金・虹の遺物は鑑定代が高い）

campaign の後ろに付けるオプション（複数可）：

| オプション | 意味 |
|---|---|
| `nocomm` | 依頼を受けない（異変はある） |
| `old` | 依頼を受けず、異変も毎週消す（§0.63までと同じ条件で比べる） |
| `types=Defeat,Survey` | 受ける依頼の種類を絞る |
| `nosteer` | 調査の部隊を完全解析の依頼の対象へ向けない |
| `from=N` | N番目のシードから回す（`campaign 1 80 from=6 trace` で1回だけ詳しく見る） |
| `selftrain` | 機嫌が60以上の週は全員が自主練、下回ったら研究を手伝う（§0.73） |
| `selftrainall` | 機嫌にかかわらず全員が自主練（§0.73） |
| `rivalry` | 訓練施設のLv3→4で専門を「切磋琢磨」にする（既定は「精鋭」。§0.76） |

結果の行「依頼（§0.64…）」に、回ごとの達成・失敗・報酬のゴールド（千G）・献上・依頼人の固有武具・異変の数を出す。
最後に、1回目の最後の状態として、各フィールドの次のボスの要求火力・ギミック・走破要求と、上位4名の火力・走破力・装備を出す（止まっている理由を見る）。
